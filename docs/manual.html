2. Qué es el sistema

Primitivos Drinks funciona con una carta digital pública y un panel de administración. El cliente elige productos (ceviche, mojitos y promos), arma el pedido y lo envía por WhatsApp. No hay pasarela de pago online: el pago se coordina como efectivo o transferencia.

Tipos de producto
  • Mojitos / bebestibles: el cliente elige sabor (1 o mezcla de hasta 2).
  • Ceviches / porciones: elige presentación; en la carta se muestra Desde $… (precio mínimo).
  • Promos: pack de varios mojitos a precio fijo; el cliente elige el sabor de cada unidad.

3. Cómo pide el cliente

  1. Entra a la web, ve el banner/logo y el estado Abierto/Cerrado.
  2. Filtra por categoría o busca productos en la carta.
  3. En cada card puede ver precio, cantidad, Ver más, añadir al carrito o pedir ahora.
  4. Si el producto tiene sabores/presentaciones/promo, primero abre el detalle para elegir.
  5. Desde el carrito o “Pedir ahora” abre Confirmar pedido.
  6. Completa cupón (opcional), extras, datos, comuna, dirección y método de pago.
  7. Pulsa Continuar a WhatsApp: se abre el chat con el pedido listo para enviar.

5. Productos, sabores y presentaciones

Producto sin variantes

Precio fijo. Útil para ítems simples o como base de una promo.

Producto con variantes

  1. Activa Usa variantes (sin precio fijo).
  2. Elige el tipo:
    • Sabor → mojitos / bebestibles.
    • Presentación → ceviches / porciones (en carta se verá “Desde $…”).
  3. Guarda el producto y luego agrega cada variante (nombre, precio, stock, imagen opcional).
En mojitos, si el cliente mezcla 2 sabores, el precio cobrado es el más alto de los elegidos. En ceviches, la carta muestra el precio mínimo como “Desde”.

Promo de mojitos

Sin variantes en el producto promo. Define la cantidad de mojitos (2–4) y el producto origen de sabores. El cliente elige un sabor por cada unidad del pack.

Descuentos de precio

Prioridad: descuento global → descuento del producto → descuento de la categoría.

6. Cupones, delivery y extras

Cupones

  • % sobre el pedido completo
  • % en categorías seleccionadas
  • % en productos seleccionados
  • Envío gratis

Puedes limitar por pedido mínimo, vigencia, solo delivery y estado activo/inactivo.

Delivery

Crea zonas por comuna con costo en CLP, tiempo estimado y estado activa/inactiva. En Configuración puedes definir un monto para Delivery gratis desde.

Extras

Ingredientes o adicionales que el cliente puede sumar en el checkout (nombre, precio, activo).

8. Recomendaciones de imágenes

  • Productos: ideal 1000 × 1000 px (cuadradas), JPG o WebP. El producto centrado con un poco de aire alrededor para que cover no recorte mal.
  • Peso: máximo 5 MB (JPG, PNG, WEBP o GIF).
  • Logo: cuadrado, fondo limpio (se muestra circular en la web).
  • Banner desktop: ancho (ej. 1600×900 o similar).
  • Banner móvil: imagen aparte, más vertical, para pantallas chicas.

9. Checklist de arranque

  1. Configura nombre, logo, banners y horarios.
  2. Ingresa WhatsApp y, si usas transferencia, la cuenta bancaria.
  3. Crea categorías (Ceviches, Mojitos, Promos…).
  4. Carga productos con imágenes y precios/variantes.
  5. Define comunas de delivery y extras.
  6. Prueba un pedido de punta a punta hasta WhatsApp (efectivo y transferencia).
  7. Opcional: crea un cupón de prueba y valida que se aplique.
