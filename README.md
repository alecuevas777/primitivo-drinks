# Primitivos Drinks

**Primitivos Drinks** es una carta digital diseñada para optimizar la experiencia de compra de los clientes, permitiéndoles explorar el menú de forma rápida e intuitiva desde cualquier dispositivo.

## Características principales

* 🍹 Carta digital moderna y responsive.
* 🦐 Secciones organizadas para ceviches, mojitos, promociones y más.
* 🛒 Carrito de compra integrado para una experiencia de pedido sencilla.
* 📲 Envío automático de pedidos mediante WhatsApp.
* ⚡ Navegación rápida y optimizada para dispositivos móviles.
* 🎨 Diseño enfocado en una experiencia visual atractiva y fácil de usar.
* ⚙️ Panel administrativo para gestionar el contenido del sitio sin necesidad de conocimientos técnicos.

## Sitio web

**Producción:** https://primitivosdrinks.cl

## Panel de administración

El sistema cuenta con un panel administrativo que permite gestionar fácilmente:

* Productos y categorías.
* Promociones.
* Información del negocio.
* Horarios de atención.
* Datos de contacto.
* Redes sociales.
* Configuración general del sitio.

---

Este proyecto fue desarrollado con un enfoque en rendimiento, facilidad de administración y una experiencia de usuario optimizada para dispositivos móviles.
